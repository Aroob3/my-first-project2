# My First Project

> "Hello, I am Aroob!"

A simple starter project featuring:
- **[index.html](index.html)**: An interactive greeting web page styled with CSS and JavaScript.
- **[main.py](main.py)**: A simple Python script that prints the greeting.
- **[hello.txt](hello.txt)**: A text file with the greeting message.

## How to Run

### In the Browser
Open `index.html` in any web browser to see the interactive greeting card.

### In Python
```bash
python main.py
```
